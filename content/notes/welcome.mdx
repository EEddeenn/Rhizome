# Welcome to Rhizome

This is your first note in the Rhizome knowledge management system.

## Features

- **Wiki-links**: Link to other notes using `[[Note Title]]` syntax
- **Backlinks**: See what notes link to the current page
- **Tags**: Organize notes with tags in the frontmatter

## Getting Started

1. Create new MDX files in `content/notes/`
2. Add frontmatter with title, date, and tags
3. Use wiki-links to connect ideas

Check out the [[Knowledge Graph Basics]] to learn more about networked thinking.

# Knowledge Graph Basics

A knowledge graph represents information as a network of interconnected ideas.

## Core Concepts

### Nodes

Each note or article in your system is a **node** in the graph.

### Edges

Links between notes create **edges** that show relationships.

## Benefits

- Discover unexpected connections
- Build a personal knowledge base over time
- See how ideas relate to each other
